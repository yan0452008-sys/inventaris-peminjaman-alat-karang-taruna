# Sistem Informasi Inventaris dan Peminjaman Alat Karang Taruna

## Deskripsi
Sistem Informasi Inventaris dan Peminjaman Alat Karang Taruna adalah aplikasi berbasis web yang dibuat untuk membantu pengelolaan data inventaris alat dan proses peminjaman serta pengembalian alat.

## Fitur
- Login pengguna
- Dashboard sistem
- Pengelolaan data anggota
- Pengelolaan data inventaris alat
- Pengajuan peminjaman alat
- Pengelolaan peminjaman dan pengembalian alat
- Laporan peminjaman

## Teknologi
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Instalasi
1. Instal dan jalankan Apache serta MySQL melalui XAMPP.
2. Ekstrak file `13_KarangTaruna.zip` ke folder `htdocs`.
3. Buat database bernama `karang_taruna` melalui phpMyAdmin.
4. Impor file `karang_taruna.sql` ke database tersebut.
5. Sesuaikan konfigurasi koneksi database pada file `koneksi.php`.
6. Buka aplikasi melalui browser menggunakan alamat `http://localhost/13_KarangTaruna/`.
